启动一个后台 shell 命令，用于持续跟踪日志、运行 watcher 或观察长时间运行的进程。普通构建或测试用 `Bash`，耗时任务可设置其 `background=true`。

命令通过 `$SHELL -c`（缺省 `bash`）在当前工作目录或已进入的 worktree 中启动。只启动一次，不会自动定时重跑、重启或根据输出判断告警条件。

立即返回 `task_id` 和启动提示，不等待完成，也不表示执行成功。用 `TaskOutput(block=false)` 查看状态和输出，用 `TaskStop` 停止。后台输出只保留有限的近期内容，详见 `TaskOutput`；任务结束时会发送状态通知，不会持续转发每条输出。命令会真实执行，其副作用取决于命令本身。
