加载一个已提供的专用技能，取得完成特定领域任务所需的指令和资源目录。系统提示词 `available_skills` 中有技能匹配当前任务时，先加载再处理任务；不要声称使用了尚未加载的技能，也不要重复加载当前上下文中已有的技能。

返回 `<skill_content>`，包含技能正文、base 目录 URI、声明的 `allowed-tools`（若有）和资源文件路径清单。相对资源路径基于该目录解析，所列文件的内容需另行读取；清单忽略目录、隐藏项和忽略规则排除的文件，不是完整目录快照。未知技能名称会报错并列出可用名称。

本工具不修改文件，也不会自动执行技能指令或运行脚本；取得内容后，由你按指令继续完成任务。
