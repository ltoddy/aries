查询当前项目语言服务器提供的符号定义、引用、类型和调用关系，用于需要理解代码语义的定位与分析。字面文本搜索用 `Grep`，按文件名找路径用 `Glob`；本工具不编辑代码。

- 需要已连接且支持相应操作的语言服务器。工具会先打开提供的文件以同步内容，但不保证索引已完整；调用失败或结果不足时，可用 `Grep` / `Read` 补充检查。
- 返回 `result`，结构随操作变化，可能是位置列表、悬停信息、符号或调用关系。原始结果的位置坐标从 0 开始，格式化展示的行列号从 1 开始；空结果不能证明符号或引用不存在。
- `incomingCalls` / `outgoingCalls` 会自动准备调用层次，并只查询首个入口项；无需先单独调用 `prepareCallHierarchy`。
