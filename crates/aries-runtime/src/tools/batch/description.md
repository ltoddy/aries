在一次调用中并发执行多个互不依赖的工具请求，用于并行读取已知文件、搜索不同范围或开展独立调研。后一个请求需要前一个结果时，应逐步调用对应工具。

- 超过调用数量上限时整批拒绝执行；不支持的子工具和嵌套 `Batch` 作为单项失败返回。可用工具见 `tool` 参数说明。
- 不保证执行或完成顺序；等待全部结束后，`results` 按输入顺序返回。每项为 `{ "success": true, "result": ... }` 或 `{ "success": false, "error": ... }`，单项失败不取消其他请求。
- 子结果保留对应工具的格式和截断限制，应逐项检查；重试时只重试需要重试的项。本工具不提供事务或回滚。
- `Agent` 仍可按其模式修改文件；只读调研须核对其实际工具范围。`TaskOutput` 默认等待任务结束，检查长期监控任务时须显式传 `block=false`，以免整个批次一直等待。

示例：并行读取两个已知文件。

```json
{"calls":[{"tool":"Read","parameters":{"file_path":"src/lib.rs"}},{"tool":"Read","parameters":{"file_path":"Cargo.toml"}}]}
```
