对同一个本地文本文件按顺序执行多次精确字符串替换，每一步都基于上一步修改后的内容。只有一次替换时用 `Edit`；只需创建文件时用 `Write`。

- 已有文件必须先用 `Read` 读取；读取后被外部修改时须重新读取。目标不存在时从空内容开始，写回时自动创建父目录。
- 与 `Edit` 不同，多处匹配时默认只修改首处，不会因匹配不唯一而拒绝。需要全部替换时显式使用 `replace_all`。
- 全部替换验证成功后才写回；任一步参数校验或匹配失败，都不会写入先前步骤的替换。
- 成功后返回 `type`（`create` / `update`）、路径与增删行数；更新已有文件时还返回原始内容和结构化 diff。
