通过 Tavily 搜索公开网络，用于查找近期信息、核实事实或发现相关页面。已有 URL 并需要正文时用 `WebFetch`，外部编程示例和 API 用法可用 `CodeSearch`，本地代码搜索用 `Grep` / `Glob`。

需要配置 `TAVILY_API_KEY`；调用会向外部服务发送查询和过滤条件，不修改本地文件。

返回查询词、结果列表和耗时；每条结果包含标题、URL 和 `description` 摘要，不是页面全文，也不保证覆盖所有相关来源或最新变化。需要上下文或精确核实时用 `WebFetch` 读取来源。

没有分页游标或完整性标记；结果不足时调整查询或域名过滤后重查。使用搜索结果作答时，附上实际支持结论的来源链接。
