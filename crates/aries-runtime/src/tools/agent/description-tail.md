执行与结果：

- 不传 `agent_id` 时创建新上下文，不自动继承主智能体对话或其他子智能体的上下文，须在 `prompt` 中提供必要信息。传入当前父会话中此前返回的 `agent_id` 时，复用该子智能体的上下文；建议保持相同的 `name`，在 `prompt` 中提供后续指令和新增信息。
- 子智能体从当前工作目录开始，与主智能体共享文件系统，没有自动隔离的工作副本；具有写入能力时，改动会直接影响这些文件。
- 调用等待子智能体完成，返回 `result`、子智能体标识 `agent_id` 和记录路径 `transcript_dir`。返回的 `agent_id` 可用于后续 Agent 调用以继续任务，但不能用于 `TaskOutput` / `TaskStop`。
- 返回内容是子智能体的汇报，不等于工作已通过验证；检查相关结果后再向用户总结，工具结果不会自动成为你的最终回复。
- 只有互不依赖、不会相互覆盖文件的任务才适合并行委派；不要并发调用同一个 `agent_id`，以免历史读写冲突。
