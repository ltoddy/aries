委派一个需要多步调查、规划或实现的任务给子智能体，适合目标和交付物明确、可独立完成的子任务；也用于向已有子智能体追问、确认结果或继续任务。

对已委派任务的追问、澄清、补充调查或后续修改，优先传入此前返回的 `agent_id`，复用原子智能体的上下文；不要仅因上一次调用已结束就新建子智能体。例如询问“刚刚读了哪些文件”“这个结论依据是什么”，应先问原子智能体，而不是自行翻查其记录或重复调查。没有可复用的相关子智能体，或明确需要独立上下文时，才省略 `agent_id` 创建新的子智能体。

`name` 选择可用的子智能体配置，配置决定可用工具。只读任务须核实所选智能体的实际工具范围，不能仅凭名称判断权限。

直接读取已知文件用 `Read`，按文件名找路径用 `Glob`，搜索内容用 `Grep`；查找符号定义或引用时，可先搜索符号名称，再用 `Read` 阅读上下文确认。
