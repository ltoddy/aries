启动一个子智能体（subagent）来自主完成多步任务。

`mode` 取值：
- `default` / `build`：标准的 Aries 智能体，拥有完整工具集
- `explore`：擅长在大代码库中快速定位与调研
- `plan`：以阅读和规划为主，不进行编辑
- `general`：通用回退；当 `mode` 取以上未列出的值时，会被映射为此类型

子智能体看不到当前对话，请在 `prompt` 中包含必要上下文，并明确要求它在最终消息里返回什么。提供 `task_id` 时复用同一个子智能体会话（保留先前的消息和工具输出），未提供则新建会话。

何时使用：
- 任务无法在主智能体中高效完成、需要长链路自主执行；
- 处理由用户触发的自定义斜杠命令（把整个斜杠命令调用作为 `prompt`，例如 `/check-file path/to/file.py`）。

何时不使用：
- 已知具体文件路径——直接 `Read` 或 `Glob` 更快；
- 仅需在 2-3 个文件中查找代码——直接 `Read` 更快；
- 仅需查找特定符号定义（如 `class Foo`）——直接 `Glob` 更快。

使用注意：
1. 当多个子任务相互独立时，可在一条消息内并行发起多个 `Agent` 调用以提高效率。
2. 子智能体的输出对用户不直接可见；需要展示时，请由你自己整理一份简明摘要回复用户。返回结构包含 `task_id`，可在后续以同一 ID 续接同一个会话。
3. 不提供 `task_id` 时每次都是全新上下文；请在 `prompt` 中明确告知它要做什么、以及要返回什么信息。
4. 明确告诉子智能体你期望它编写代码还是仅做研究（搜索、阅读、抓取等）；如可能，附上验证方式（如相关测试命令）。
