对同一个文件依次执行多次查找替换。

- 如果文件不存在，会从空内容开始；写入前会自动创建父目录。
- 编辑按数组顺序依次应用；每一步都基于上一步的结果。请避免前一次编辑改掉了后一次编辑要查找的文本。
- `old_text` 必须与当前内容完全匹配（包括空白和缩进）。
- 如果某次编辑的 `old_text` 与 `new_text` 相同，整个调用失败。
- 如果 `old_text` 非空但在当前内容中找不到，整个调用失败，并且文件不会被写回。
- 整个 `edits` 序列必须全部成功，结果才会写入磁盘。
- 当 `old_text` 为空字符串时，当前实现会**直接用 `new_text` 整体替换**当前内容，这会丢弃此前的所有内容；请仅在确实希望覆盖整个文件时这样使用。
