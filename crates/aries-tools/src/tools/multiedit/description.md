对同一个本地文本文件按顺序执行多次精确字符串替换，全部替换成功后再写回。只有一次替换时用 `Edit`；只需创建文件时用 `Write`。

- `file_path` 支持绝对路径或相对于当前工作目录（包括已进入的 worktree）的路径。已有文件必须先用 `Read` 读取；读取后被外部修改时须重新读取。
- `edits` 按数组顺序应用，每一步的 `old_text` 匹配上一步修改后的内容。原文须保留空白、缩进和换行，不包含 `Read` 的行号或 `→` 前缀，也不支持正则表达式。
- 每项的 `replace_all` 默认 `false`：只替换首个匹配，出现多处匹配也不会报错，这与 `Edit` 不同。设为 `true` 则替换该文件中的全部匹配。
- `new_text` 可为空以删除匹配内容，但不能与 `old_text` 相同。非空 `old_text` 找不到时，整个调用失败且不会写回之前的替换。
- `old_text=""` 仅在该步处理的内容为空时可用，以 `new_text` 整体写入。目标文件不存在时从空内容开始，写回时自动创建父目录。
- 成功后文件已创建或更新；返回 `type`（`create` / `update`）、路径与增删行数，更新已有文件时还返回原始内容和结构化 diff。
