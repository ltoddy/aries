- 允许助手搜索网络，并使用搜索结果来完善回答
- 提供最新事件和近期数据的实时信息
- 返回搜索结果信息，包括标题、URL 和描述
- 用于获取超出模型知识截止日期之外的信息
- 搜索在单次 API 调用中自动完成

强制要求 - 你必须遵守：
  - 回答完用户的问题后，必须在回复末尾附上 "Sources:"（来源）部分
  - 在 Sources 部分中，将搜索结果中的相关 URL 以 markdown 超链接形式列出：[标题](URL)
  - 这是强制性的——绝不能在回复中省略来源
  - 示例格式：

    [你的回答]

    Sources:
    - [来源标题 1](https://example.com/1)
    - [来源标题 2](https://example.com/2)

使用说明：
  - 支持域名过滤：`allowed_domains` 将结果限制在指定域名内，`blocked_domains` 排除指定域名
  - 该工具是只读的，不会修改任何文件

重要 - 在搜索查询中使用正确的年份：
  - 搜索近期信息、文档或时事时，请使用当前年份。
  - 示例：如果用户问"最新 React 文档"，应搜索"React 文档"并加上当前年份，而不是去年。
