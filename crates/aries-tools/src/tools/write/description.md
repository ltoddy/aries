创建本地文本文件，或向已有空文件写入完整内容。修改已有非空文件请用 `Edit` 或 `MultiEdit`。

- `file_path` 支持绝对路径或相对于当前工作目录的路径；进入 worktree 后，相对路径基于该 worktree。不存在的父目录会自动创建。
- `content` 是要写入的完整文本，不是补丁，也不会追加到文件末尾。
- 新文件无需预先读取；已有空文件必须先用 `Read` 读取，且此后未被外部修改。已有非空文件会被拒绝，即使内容与本次写入相同。
- 成功后内容已写入磁盘，返回 `file_path` 和新增行数 `additions`。重复调用可能因文件已非空而失败，不要把成功写入当成可直接重试的操作。
- 除非用户明确要求，否则不要创建文档文件（如 Markdown 或 README）。
