通过 Firecrawl 抓取一个已知网页，用于阅读用户给出的链接或搜索结果正文。尚不知道地址时先用 `WebSearch`；读取本地文件用 `Read`。

- URL 会发送到配置的 Firecrawl 服务，依赖可用的服务配置（`FIRECRAWL_API_URL` / `FIRECRAWL_API_KEY`）。工具没有请求头、Cookie 或登录参数，不会继承浏览器登录态；受限页面能否读取取决于服务能力和配置。
- 返回 `content`，即服务提取的 Markdown，不包含原始 HTML、响应元数据或分页游标。完整性取决于抓取结果；没有 `markdown` 字段时返回空字符串，不能据此判断网页本身没有内容。
- 只请求指定页面，不会递归抓取网站；其他页面需分别调用。不修改本地文件，也不执行网页中的后续操作。
