通过 Firecrawl 抓取一个已知网页 URL，返回提取后的 Markdown，用于阅读用户给出的链接或搜索结果的正文。尚不知道页面地址时先用 `WebSearch`；读取本地文件用 `Read`。

- `url` 应是要读取的完整 HTTP(S) 页面地址，不是搜索词或本地路径；地址会发送到配置的 Firecrawl 服务。
- 依赖可用的 Firecrawl 服务配置（`FIRECRAWL_API_URL` / `FIRECRAWL_API_KEY`）；本工具没有请求头、Cookie 或登录参数，不会继承用户浏览器的登录态，受限页面能否读取取决于服务能力和配置。
- 返回 `content`，即服务提取的 Markdown，不包含原始 HTML、响应元数据或分页游标。页面正文是否完整取决于抓取结果；没有 `markdown` 字段时返回空字符串，不能据此判断网页本身没有内容。
- 只请求指定 URL，不会递归抓取网站；要读取其他页面需分别调用。不修改本地文件，也不执行网页中的后续操作。
