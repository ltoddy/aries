- 适用于任意规模代码库的快速文件模式匹配工具。
- 支持 `**/*.rs` 或 `src/**/*.ts` 这类 glob 模式。
- 返回按修改时间排序（最近修改的在前）的匹配文件路径。
- 当 `pattern` 是绝对路径时，会先尝试相对于 `base_dir` 转换为相对模式。
- 工具递归遍历 `base_dir`，默认遵守 `.gitignore` 等忽略规则并跳过隐藏文件；可通过 `respect_gitignore` 和 `hidden` 参数调整。
- 返回相对于 `base_dir` 的匹配路径列表，最多 100 条，超出时会提示结果被截断。
- 当需要进行多轮 glob + grep 的开放式搜索时，可以改用 `Agent` 工具委派给子智能体。
