按文件名或路径模式查找本地文件，用于定位已知名称、扩展名或目录下的文件。搜索文件内容用 `Grep`，查看已知文件用 `Read`；本工具只返回文件路径，不返回内容或目录项。

- `pattern` 是相对于 `base_dir` 的 glob 模式，如 `**/*.rs`、`src/**/*.ts`，不是正则表达式。绝对模式位于 `base_dir` 下时会转换为相对模式；需要搜索其他目录时应显式设置 `base_dir`。
- `base_dir` 默认当前工作目录（包括已进入的 worktree），也可传绝对目录或相对目录。搜索会递归遍历该目录。
- 默认跳过隐藏文件和目录，并遵循 `.gitignore` 等忽略规则；`hidden=true` 包含隐藏项，`respect_ignore=false` 关闭忽略规则，两者独立控制。
- 返回相对于 `base_dir` 的 `files`，按修改时间从新到旧排列。将结果传给 `Read` 时，要结合 `base_dir` 还原路径。
- `limit` 默认 100，传 0 不限数量。`truncated=true` 表示还有匹配路径未返回；缩小目录或模式、或提高限额后重查，没有分页游标。
- 不修改文件。遍历中无法访问的条目会被跳过，因此无结果不一定代表文件不存在。
