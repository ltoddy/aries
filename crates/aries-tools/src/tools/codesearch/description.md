通过 Exa 远程服务检索第三方库、SDK、API 和框架的代码示例与文档片段，用于了解外部依赖的用法或编程概念。本地代码搜索用 `Grep` / `Glob`，一般网络信息搜索用 `WebSearch`，阅读已知网页用 `WebFetch`。

- `query` 应包含库或框架名、具体 API 或问题，必要时带版本，例如“React useState functional update examples”。查询会发送给 Exa，不会读取本地项目文件。
- `tokens_num` 是向服务请求的内容 token 预算，默认 5000；实际返回量由服务决定，不保证精确达到该数量。
- 返回 `results` 文本，来自服务响应中的首个内容片段，不代表完整文档或全部搜索结果；需要完整页面或版本确认时继续读取相关来源。
- 未取得内容时返回提示，可缩小问题、补充库名或修正拼写后重查。依赖网络和远程服务可用性，不修改本地文件。
