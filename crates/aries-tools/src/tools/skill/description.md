加载一个已提供的专用技能，取得完成特定领域任务所需的指令和资源目录。适用于系统提示词 `available_skills` 中有技能匹配当前任务时；本工具返回指令，后续由你按指令执行，不会自动运行脚本或完成任务。

- `name` 必须精确匹配 `available_skills` 中的技能名称，区分大小写；不是文件路径、任意技能搜索词或 `/help` 等 CLI 命令。未知名称会报错并列出可用名称。
- 当技能匹配用户请求时，先调用本工具再处理该任务；不要声称使用了尚未加载的技能，也不要重复加载当前上下文中已经取得的技能。
- 返回 `<skill_content>`，包含技能正文、base 目录 URI、声明的 `allowed-tools`（若有）和资源文件路径清单。相对资源路径基于该目录解析，所列文件的内容需另行读取。
- 本工具不修改文件，也不执行技能中的命令。资源清单忽略目录、隐藏项和忽略规则排除的文件，不能当作完整目录快照。
