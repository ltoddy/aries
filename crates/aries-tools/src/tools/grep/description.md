在当前工作目录（包括已进入的 worktree）下递归搜索本地文件内容，用于根据函数名、报错文本或配置项定位代码。按文件名找路径用 `Glob`，读取已知文件用 `Read`，查询符号的语义定义或引用可用 `Lsp`。

- 逐行匹配；默认跳过隐藏项并遵循 `.gitignore` 等规则，可通过参数调整。遇到二进制 NUL 字节会停止搜索该文件。
- 返回 `matches` 和 `truncated`，路径相对于工作目录。默认只返回匹配文件路径，需要行内容时选择 `output_mode="content"`。文件列表按修改时间从新到旧排列，其余模式的结果顺序不固定。
- `content` 中匹配行用 `:` 分隔，上下文行用 `-` 分隔。达到限额后仍保留已选匹配的后置上下文，其中再次命中的行也只作为上下文展示。
- `truncated=true` 表示还有匹配被省略，应缩小范围或提高限额后重查，没有分页游标。无结果只代表当前范围和过滤条件下未找到匹配。
- 不修改文件。遍历、读取或忽略规则解析失败会报错；`content` 模式下超长行或上下文超过 10 MiB 搜索缓冲区也会报错。
