在一个已有本地文本文件中执行一次精确字符串替换，用于已知原文的局部修改。对同一文件执行多步替换用 `MultiEdit`，创建文件用 `Write`。

- `file_path` 支持绝对路径或相对于当前工作目录（包括已进入的 worktree）的路径。文件必须存在，并已用 `Read` 读取；若读取后被外部修改，重新读取再编辑。
- `old_text` 是原文，不是正则表达式，必须逐字匹配，包括空白、缩进和换行。从 `Read` 复制时去掉行号与 `→` 前缀。
- `new_text` 是替换后的文本，可为空以删除匹配内容，但不能与 `old_text` 相同。
- 默认 `replace_all=false`，要求 `old_text` 唯一匹配；无匹配或多处匹配都会报错。出现多处匹配时，扩展原文上下文或明确设为 `true`。
- `replace_all=true` 只替换当前文件中的所有匹配，不会跨文件查找，也不是语义重命名。
- 成功后文件已写回；返回路径、修改前内容、结构化 diff 以及增删行数。校验或匹配失败时不会写回，调整参数或重新读取后再调用。
