读取本地文本文件，用于查看已知路径的代码、配置或日志，以及在编辑前确认当前内容。按文件名找路径用 `Glob`，按内容定位文件用 `Grep`；不支持目录、二进制、图片或 PDF。

返回 `content` 和 `truncated`。内容中的「行号 + `→`」是展示前缀，不属于文件原文；空文件返回提示。`truncated=true` 表示片段后还有行，用 `offset` 从最后一行的下一行继续读取；`false` 只表示已到文件末尾，不代表读过起始位置之前的内容。

不修改文件；成功读取会记录文件状态，供 `Write`、`Edit`、`MultiEdit` 校验。文件后来被外部修改时，应重新读取后再编辑。
