读取本地文本文件，用于查看已知路径的代码、配置或日志，以及在编辑前确认当前内容。按文件名找路径用 `Glob`，按内容定位文件用 `Grep`。

- `file_path` 支持绝对路径或相对于当前工作目录的路径；进入 worktree 后，相对路径基于该 worktree。
- `offset` 是从 1 开始的起始行号，默认 1，传 0 也按 1 处理；`limit` 是最多读取的行数，默认 2000，须为正整数。可用两者读取指定片段或继续分页。
- 返回 `content` 和 `truncated`。内容中的「行号 + `→`」是展示前缀，不属于文件内容；编辑时只取箭头后的原文并保留缩进。
- `truncated=true` 表示返回片段之后还有行，可从最后一行的下一行继续读取；`false` 只表示已到文件末尾，不代表读过 `offset` 之前的内容。空文件返回提示。
- 只支持文本文件，不支持目录、二进制、图片或 PDF。列出目录内的文件路径请用 `Glob`。
- 不修改文件；成功读取会记录文件状态，供 `Write`、`Edit`、`MultiEdit` 校验。文件后来被外部修改时，应重新读取后再编辑。
