从本地文件系统读取文本文件内容。

- `file_path` 可以是绝对路径，也可以是基于当前工作目录的相对路径。
- 默认从文件开头最多读取 2000 行，超出部分会被截断，此时 `truncated` 为 `true`。文件不超过 2000 行时，不带 `offset`/`limit`
  即可一次读完；更长时用这两个参数分段读取。
- `offset` 为起始行号（1 起始；传入小于 1 的值会被当作 1）；`limit` 为读取行数，必须大于 0。
- 返回结果采用类似 `cat -n` 的格式：每行带右对齐的行号，行号与内容之间以 `→` 分隔；行号是文件中的绝对行号（第 1 行为 1，带
  `offset` 时首行行号即 `offset`）。
- 若读取的文件存在但内容为空，会返回一条提示，而不是空内容。
- 只能读取文件，不能读取目录；读取目录会返回明确错误，列目录请改用 `Glob` 工具。
- 不会处理二进制、图片或 PDF；这些情况会以错误返回。
- 如果不确定文件路径，可先用 `Glob` 定位。
- 多个独立文件可以并行调用此工具。
