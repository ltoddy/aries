启动一个后台 shell 命令，用于持续跟踪日志、运行 watcher 或观察长时间运行的进程。只运行一次的构建或测试可用 `Bash`，耗时任务可设置其 `background=true`。

- `command` 应是无需交互输入的完整命令；工具只启动一次，不会自动定时重跑、重启或根据输出判断告警条件。持续监视或循环行为须由命令自身实现。
- 命令通过 `$SHELL -c`（缺省 `bash`）在当前工作目录或已进入的 worktree 中启动；`description` 是可选的任务用途说明。
- 立即返回 `task_id` 和启动提示，不等待完成，也不表示命令已执行成功。用 `TaskOutput` 配合 `block=false` 查看当前状态和输出，用 `TaskStop` 停止。
- 命令会真实执行，其副作用取决于命令本身；后台输出仅保留有限的近期内容，详见 `TaskOutput`。任务结束时会发送状态通知，不会持续转发每条输出。
