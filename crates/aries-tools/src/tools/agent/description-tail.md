调用要求与结果：

- `mode` 使用内置类型或已列出的自定义名称。自定义名称优先匹配且不区分大小写，可覆盖同名内置模式；未知名称回退为 `general`。只读任务应选择未被覆盖的内置 `explore` / `plan`，或核实所选自定义智能体仅提供只读工具，不要仅凭名称判断权限。
- `description` 是简短的任务标题；`prompt` 是完整任务说明，应包含目标、背景、相关路径、约束、期望交付物及必要的验证方式，并说明是否允许修改代码。
- 子智能体不继承当前对话，每次调用都是新会话。它从当前工作目录开始，文件系统与主智能体共享，并不会自动获得隔离的工作副本；具有写入能力时，改动会直接影响这些文件。
- 调用会等待子智能体完成，返回 `result`、标识本次会话的 `task_id` 和记录路径 `transcript_path`。`task_id` 不能用于 `TaskOutput` / `TaskStop`，也不支持据此续接会话。
- 返回内容是子智能体的汇报，不等于工作已通过验证；检查相关结果后再向用户总结，工具结果不会自动成为你的最终回复。
- 多个任务只有在互不依赖、不会相互覆盖文件时才并行委派；新一轮调用不会自动接收前一次的结论，需在 `prompt` 中补充。
