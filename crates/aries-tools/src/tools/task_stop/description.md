- `task_id` 必须取自本会话 `Bash(background=true)`、`Monitor` 的返回值或任务通知；不接受进程 PID 或 `Agent` 会话 ID。
- 会向任务的 shell 进程发送终止请求，不保证终止其派生的所有子进程，也不会回滚命令已产生的文件或外部变更。
- 返回任务 ID、类型、最终状态和原命令；保留的输出可继续通过 `TaskOutput` 查看。已完成、失败、停止或不存在的任务会报错，重复停止不是无操作成功。
- 若等待停止确认超过 2 秒会报超时，但终止请求可能已生效；先用 `TaskOutput(block=false)` 核对状态，不要直接假定任务仍在运行。
