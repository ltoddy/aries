这是一个用于在一次操作中对单个文件进行多次编辑的工具。它构建在 Edit 工具之上，允许您高效地执行多次查找和替换操作。当您需要对同一个文件进行多次编辑时，请优先使用此工具而不是 Edit 工具。

在使用此工具之前：

1. 使用 Read 工具了解文件的内容和上下文
2. 验证目录路径是否正确

要进行多次文件编辑，请提供以下信息：
1. file_path：要修改的文件的绝对路径（必须是绝对路径，不能是相对路径）
2. edits：要执行的编辑操作数组，其中每个编辑包含：
   - oldString：要替换的文本（必须与文件内容完全匹配，包括所有空格和缩进）
   - newString：用于替换 oldString 的编辑后的文本
   - replaceAll：替换所有出现的 oldString。此参数是可选的，默认为 false。

重要提示：
- 所有编辑按提供的顺序依次应用
- 每个编辑都在上一个编辑的结果之上进行操作
- 必须所有编辑都有效才能成功执行操作 - 如果任何一个编辑失败，将不会应用任何编辑
- 当您需要对同一个文件的不同部分进行多处更改时，此工具非常理想

关键要求：
1. 所有编辑遵循与单个 Edit 工具相同的要求
2. 编辑是原子性的 - 要么全部成功，要么全部不应用
3. 仔细计划您的编辑，以避免顺序操作之间的冲突

警告：
- 如果 edits.oldString 与文件内容不完全匹配（包括空格），工具将失败
- 如果 edits.oldString 和 edits.newString 相同，工具将失败
- 由于编辑是按顺序应用的，请确保较早的编辑不会影响较晚编辑试图查找的文本

进行编辑时：
- 确保所有编辑产生惯用、正确的代码
- 不要让代码处于损坏状态
- 始终使用绝对文件路径（以 / 开头）
- 仅在用户明确要求时使用表情符号。除非被要求，否则避免向文件添加表情符号。
- 使用 replaceAll 在整个文件中替换和重命名字符串。例如，如果您想重命名一个变量，此参数非常有用。

如果您想创建一个新文件，请使用：
- 新的文件路径，如果需要的话包括目录名
- 第一个编辑：空的 oldString 和作为 newString 的新文件内容
- 后续编辑：在创建的内容上进行正常的编辑操作
