启动一个新的智能体 (Agent) 来自主处理复杂的多步任务。

可用的智能体类型及其可以访问的工具：
- default/build: The standard Aries agent with all standard tools
- explore: Fast agent specialized for exploring codebases
- plan: Planning agent that can read but not edit
- general: Fallback general-purpose agent type used by the current implementation

使用 Task 工具时，您必须指定一个 `subagent_type` 参数来选择要使用的智能体类型。当前实现中，未知值会回退到 `general`。

何时使用 Task 工具：
- 当您被指示执行自定义斜杠命令时。将带有斜杠命令调用的 Task 工具作为整个提示。斜杠命令可以带参数。例如：Task(description="检查文件", prompt="/check-file path/to/file.py")

何时不使用 Task 工具：
- 如果您想读取特定的文件路径，请使用 Read 或 Glob 工具而不是 Task 工具，以便更快地找到匹配项
- 如果您正在搜索特定的类定义（如 "class Foo"），请改用 Glob 工具以更快地找到匹配项
- 如果您正在特定文件或一组 2-3 个文件中搜索代码，请使用 Read 工具而不是 Task 工具以更快地找到匹配项
- 与上述智能体描述无关的其他任务

使用说明：
1. 尽可能同时启动多个智能体，以最大限度地提高性能；为此，请在单个消息中使用多个工具调用
2. 当智能体完成任务时，它将向您返回一条消息。智能体返回的结果对用户不可见。要向用户显示结果，您应该向用户发送一条包含结果简明摘要的文本消息。输出包含一个 `task_id`，您可以在以后重用它来继续同一个子智能体会话。
3. 除非您提供 `task_id` 来恢复同一个子智能体会话（该会话将继续其先前的消息和工具输出），否则每次智能体调用都从一个全新的上下文开始。当重新开始时，您的提示应包含一个高度详细的任务描述，以便智能体自主执行，并且您应明确指定智能体在其最后也是唯一给您的消息中应该向您返回什么信息。
4. 智能体的输出通常应该被信任
5. 清楚地告诉智能体您是期望它编写代码还是仅进行研究（搜索、文件读取、Web 获取等），因为它不知道用户的意图。如果可能的话，告诉它如何验证其工作（例如，相关的测试命令）。
6. 如果智能体描述中提到应该主动使用它，那么您应该尽量在用户没有事先要求的情况下使用它。运用您的判断力。
