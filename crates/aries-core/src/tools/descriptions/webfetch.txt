- 从指定的 URL 获取内容
- 接受一个 URL 和可选的 `format` 作为输入
- 当前实现会获取页面文本内容，并返回截断后的字符串结果
- 当您需要检索和分析 Web 内容时使用此工具

使用说明：
- 重要提示：如果存在另一个提供更好 Web 获取功能、更针对任务或限制更少的工具，请优先使用该工具而不是此工具。
- URL 必须是格式完全正确的有效 URL
- HTTP URL 将自动升级为 HTTPS
- schema 中支持的格式选项为 `markdown`、`text` 或 `html`，但当前实现尚未根据该选项做实际格式转换
- 此工具是只读的，不会修改任何文件
- 如果内容非常大，结果可能会被截断
