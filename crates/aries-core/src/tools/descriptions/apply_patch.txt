使用 `apply_patch` 工具编辑文件。您的补丁语言是标准的统一差异（Unified Diff）格式，旨在易于解析和安全应用。

您必须提供标准的统一差异格式，例如：

```diff
--- a/src/app.py
+++ b/src/app.py
@@ -1,3 +1,3 @@
 def greet():
-    print("Hi")
+    print("Hello, world!")
```

对于创建新文件：
```diff
--- /dev/null
+++ b/hello.txt
@@ -0,0 +1,1 @@
+Hello world
```

对于删除文件：
```diff
--- a/obsolete.txt
+++ /dev/null
@@ -1,1 +0,0 @@
-This file is obsolete
```

请务必记住：
- 使用 `diffy` 库来应用补丁，它期望标准的 `--- a/` 和 `+++ b/` 标头以及 `@@` 上下文块。
- 提供足够的上下文（`-` 和 ` ` 行）以确保补丁能够正确匹配原始文件。
