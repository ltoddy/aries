- 从指定的 URL 获取内容
- 接受一个 URL 和可选的格式作为输入
- 获取 URL 内容，转换为请求的格式（默认为 markdown）
- 以指定的格式返回内容
- 当您需要检索和分析 Web 内容时使用此工具

使用说明：
  - 重要提示：如果存在另一个提供更好 Web 获取功能、更针对任务或限制更少的工具，请优先使用该工具而不是此工具。
  - URL 必须是格式完全正确的有效 URL
  - HTTP URL 将自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具是只读的，不会修改任何文件
  - 如果内容非常大，结果可能会被总结/截断
